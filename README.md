# 🎮 League of Legends Champions Wiki

An interactive wiki dedicated to showcasing **League of Legends** champions. The site features a modern and responsive user interface to provide the best experience for the gaming community.

🔗 **[Live Demo](https://anasfz.github.io/lol-champions-wiki/)**

---

## ✨ Features
- 🖥️ **Responsive Design:** Fully adapts to desktop, tablet, and mobile screens.
- ⚡ **Fast Performance:** Smooth and lightweight browsing experience for viewing champion stats and lore.
- 🎨 **Attractive UI:** Clean design focused on providing the best User Experience (UX/UI).

## 🛠️ Tech Stack
- **HTML5** 
- **CSS3** (Flexbox / Grid)
- **JavaScript**
- **Hosting:** [GitHub Pages](https://pages.github.com/)
